# Specification-driven development

RoleCallAI uses testable requirement IDs so product claims stay linked to code.

1. Update [rolecallai-v1.md](rolecallai-v1.md) with measurable acceptance.
2. Record security, privacy, regional, cost, and lifecycle effects.
3. Implement the smallest scoped change without weakening control.
4. Add deterministic tests; use ADK evaluation for non-deterministic behavior.
5. Update [traceability.md](traceability.md) with source and evidence.
6. Update deployment evidence only after a real rollout.
